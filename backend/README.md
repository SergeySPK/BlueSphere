# Blue Sphere — Backend

Backend приложения «Blue Sphere» — серверная часть на Python с использованием FastAPI и PostgreSQL.

## Требования

- Python 3.13
- PostgreSQL
- Установленные зависимости проекта

Для запуска через Docker дополнительно требуется Docker.

## Настройка окружения

Перейдите в каталог backend:

```bash
cd backend
```

Создайте виртуальное окружение:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install .
```

Создайте файл `.env` в каталоге `backend` и укажите необходимые переменные:

```dotenv
DATABASE_URL=postgresql+psycopg://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@ХОСТ:5432/ИМЯ_БАЗЫ?sslmode=require
BOT_TOKEN=ТОКЕН_БОТА
FRONTEND_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```

Замените примеры на свои значения. Не добавляйте `.env` в Git и не публикуйте токен бота или пароль базы данных.

`DATABASE_URL` должен содержать параметры подключения к вашей базе PostgreSQL. Для локальной базы при необходимости используйте подходящий адрес и порт.

## Подготовка базы данных

При активированном виртуальном окружении и настроенном `DATABASE_URL` выполните:

```bash
alembic upgrade head
```

Команда применит миграции и создаст структуру базы данных.

### Демонстрационные данные

Если для проверки нужны демонстрационные школа и классы, сначала выполните:

```bash
python seed.py
```

Для создания демонстрационных учителей, предметов и расписания затем выполните:

```bash
python seed_schedule.py
```

Эти команды добавляют демонстрационные данные. Не запускайте их на рабочей базе без предварительной проверки их содержимого.

## Запуск сервера

Из каталога `backend` выполните:

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

После запуска API будет доступно по адресу:

- Главная страница: http://127.0.0.1:8000/
- Документация API: http://127.0.0.1:8000/docs

Для остановки сервера нажмите `Ctrl+C`.

## Запуск через Docker

Из корня репозитория выполните:

```bash
docker build -t bluesphere-backend ./backend
```

Для запуска контейнера необходимо передать ему переменные окружения `DATABASE_URL` и `BOT_TOKEN`. При необходимости также задайте `FRONTEND_ORIGINS`.

Пример запуска:

```bash
docker run --rm -p 3000:3000 \
  -e DATABASE_URL \
  -e BOT_TOKEN \
  -e FRONTEND_ORIGINS \
  bluesphere-backend
```

Контейнер применяет миграции при старте и запускает API на порту `3000` либо на порту, заданном переменной `PORT`.

## Важные замечания

- Не храните пароли, токены и другие секреты в исходном коде.
- Для подключения к базе данных используйте переменную `DATABASE_URL`.
- Перед изменением схемы базы данных создавайте миграции Alembic.
- Демонстрационные данные предназначены для разработки и проверки, а не для заполнения рабочей базы.
